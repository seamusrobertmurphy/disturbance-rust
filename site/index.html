How the check works

It searches a public catalogue of Sentinel-2 scenes, using the STAC standard, for each date window. It drops cloud, shadow and snow using the scene classification that comes with each scene. It takes the middle value of each 20 m pixel across the clear views. From those it computes three indices: NDVI for canopy greenness, NDMI for canopy moisture and NBR for burning. The change in each index between the windows is split into low, moderate and high classes at the SOP's thresholds. Pixels that were water in either window are left out.

The method is a port of the disturbance checker, version 0.14.3, and gives the same class for every pixel.
